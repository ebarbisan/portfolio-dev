# 🚀 Portfólio Profissional - Estevan Barbisan

Este é o meu portfólio profissional, desenvolvido com foco em performance, design moderno e minimalismo. O objetivo é apresentar minha trajetória como desenvolvedor de software em início de carreira, com foco em back-end, arquitetura de sistemas e soluções funcionais.

## 🎨 Identidade Visual
O projeto utiliza uma estética **Dark Tech**, com uma paleta de cores baseada em tons escuros, verde neon e ciano, transmitindo tecnologia, energia e evolução.

- **Fundo Principal:** `#080C0B`
- **Destaques:** Verde (`#39F5A5`) e Ciano (`#32D9E8`)

## 🛠️ Stack Tecnológica
O site foi construído utilizando as tecnologias mais modernas do ecossistema React:

- **Framework:** [Next.js 14+](https://nextjs.org/) (App Router)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Animações:** [Framer Motion](https://www.framer.com/motion/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Hospedagem:** [Vercel](https://vercel.com/)

## 📂 Estrutura do Projeto
A arquitetura foi pensada para ser simples e de fácil manutenção:

- `src/app/`: Páginas, layouts e estilos globais.
- `src/components/`: Componentes de interface reutilizáveis.
- `src/data/`: Centralização de dados (textos, links e projetos) para facilitar edições rápidas via `siteConfig.ts`.

## 🚀 Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/ebarbisan/portfolio-dev.git
   ```

2. Entre na pasta do projeto:
   ```bash
   cd portfolio-dev
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Acesse `http://localhost:3000` no seu navegador.
